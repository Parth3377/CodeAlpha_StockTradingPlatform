# Stock Trading Platform

## 📖 About

Stock Trading Platform is a Java console-based application developed as part of the **CodeAlpha Java Programming Internship**. The application simulates a basic stock trading environment where users can buy and sell stocks, manage their investment portfolio, and track transaction history. The project demonstrates the implementation of Object-Oriented Programming concepts and Java Collections Framework.

---

## ✨ Features

- Buy and sell stocks
- Manage user portfolio
- View available stocks
- Track transaction history
- Display portfolio details
- Console-based user interface

---

## 🛠 Technologies Used

- Java
- Java Collections Framework
- Object-Oriented Programming (OOP)
- Console-Based Application

---

## 📚 OOP Concepts Used

- Classes & Objects
- Encapsulation
- Methods
- Constructors

---

## ▶️ How to Run

1. Clone this repository.
2. Open the project in any Java IDE (VS Code, IntelliJ IDEA, Eclipse, etc.).
3. Compile all Java files.
4. Run `Main.java`.
5. Follow the on-screen instructions to buy, sell, and manage stocks.
